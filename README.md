# Extractor de significado en textos

Herramienta con interfaz grafica que clasifica descripciones de activos fijos
usando un LLM via Ollama.

## Origen
El codigo base fue desarrollado durante una practica profesional, previo al inicio del curso. Durante este periodo se agregaron:
- Priorizacion de filas por columna
- Filtro por rango especifico de filas
- Actualizacion de interfaz

## Ejecucion
python3 Extractor_de_significado_en_textos.py
